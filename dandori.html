Dandori Mach I/P

Langkah-Langkah

  1. Arahkan kursor ke no prog, kemudian ganti sesuai tipe
  2. Pastikan angka hobb o.d sama dengan program 23 & 24, dengan cara:
    1. Ubah mode memory: on
    2. Tekan prog, cr/ed
    3. Masukkan nomor program
    4. Tekan input lalu klik yes
    5. Tekan hobbing, lihat nomor 6 (obd od)
    6. Return sebanyak 2× kemudian yes dan return lagi 2×
  3. Setting Op60
    Ubah mode select ke edit. Memory edit: on, klik no program di panel (bukan di layar), pilih program, masukkan nomor program. Tekan “no” atau masukkan nomor kemudian tekan o srh. Pastikan nomor program di layar sama dengan di panel. Ubah memory edit menjadi off dan mode auto.
  4. Ubah posisi Z-axis shv g.2
    Memory: edit, memory edit: on, axis select pilih Z. Di halaman “cut” pada nomor 1 ubah nilai sesuai tipe:
    • BZ100 ➜ BZ110 → kurangi 900 (-900)
    • BZ110 ➜ BZ100 → tambah 900 (+900)
Tambahan! Cara cleaning tool SHV G.Reverse:
Manual → Cutter Change → Cutter Unclamp → Lepas tool dan bersihkan.
